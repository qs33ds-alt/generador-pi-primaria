# Generador de PI · 0.76

Aplicació pública amb pantalla d’entrada i dades locals. Basada en la versió 0.75.

Per activar la web: Settings → Pages → Deploy from a branch → main → /(root) → Save.

Els PI es desen només al navegador. Exporta el JSON per conservar una còpia o canviar de dispositiu. No pugis dades d’alumnes al repositori.
