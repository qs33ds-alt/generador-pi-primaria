# Generador de PI · v0.88.2

Publicació GitHub Pages des de main / arrel.

Banc de 313 criteris i 1.565 propostes generals, cinc per criteri. Català i Matemàtiques es conserven íntegrament. Ciutadana, Emprenedora i Medi tenen una nova redacció segons el mateix model; CPSAA incorpora etiquetes específiques i ajustos de redacció.

Els criteris curriculars originals no s’han modificat. Les propostes seleccionades en PI anteriors es mantenen amb el seu text i es poden combinar amb les noves.

Compilació de producció i 15 suites de proves superades, incloses importació, persistència i exportacions Word/PDF.

Els PI es desen al navegador. Exporta el JSON per conservar una còpia. No pugis dades d’alumnes al repositori.
